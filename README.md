## 🚀 Featured Projects

### 🤖 Fin-Soko Pride

> **Reimagining financial inclusion through responsible AI.**

Fin-Soko Pride is an AI-powered lending intelligence prototype designed around the realities of informal economies and SACCOs in East Africa.

The project explores how AI can support lending decisions using **contextual financial signals while keeping human beings responsible for final decisions.**

### My Contribution

I personally worked on:

* 🤖 Building the **n8n agentic workflow**
* 🧩 Implementing the **Scout, Guardian, and Hunter agents**
* 🔄 Connecting the different stages of the AI workflow
* 🧠 Designing prompts and analysis flows
* ⚖️ Working on the project's **responsible-AI and human-oversight principles**
* 🛡️ Exploring how uncertainty and bias should be handled in AI-assisted decisions
* 🚀 Helping build and deploy the working prototype

The project was developed during the **PLP AI Safari**, a four-week intensive learning experience. It was an important opportunity to move from learning AI concepts into actually building an AI-powered application.

**Stack:** `n8n` `Generative AI` `JavaScript` `Vercel` `AI-assisted development`

[![View Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge\&logo=github)](https://github.com/Mason-hun/pride-sokoni-path-bf86ad2c)

> **AI-powered continuity management for television writers' rooms.**

CanonSync AI explores how AI can help maintain consistency across a show's evolving canon.

The system processes information from submitted scenes and uses AI-powered workflows to identify potential continuity issues.

### My Contribution

* 🤖 **IBM Granite integration**

This project gave me hands-on exposure to integrating AI capabilities into a larger software system and helped me understand the difference between simply using an AI API and designing an application around AI.
