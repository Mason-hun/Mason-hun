## 🚀 Featured Projects

### 🎬 CanonSync AI

**AI-powered continuity management for television writers' rooms.**

CanonSync helps writers maintain a consistent source of truth for a show's canon by extracting facts from scenes, retrieving relevant canon using semantic search, and detecting potential contradictions using LLM-based reasoning.

**My contribution:** Project leadership & AI integration.

I worked on the AI pipeline, LLM provider architecture, fact extraction, prompt engineering, structured AI outputs, embeddings, semantic retrieval, and contradiction analysis.

**Stack:**  
`IBM Granite` `IBM Slate` `Node.js` `Express` `Next.js` `PostgreSQL` `pgvector`
