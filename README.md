## 🚀 Featured Projects

### 🤖 CanonSync AI

> **AI-powered continuity management for television writers' rooms.**

CanonSync AI acts like **version control for a show's canon**.

It extracts facts from newly submitted scenes, generates semantic embeddings, retrieves relevant established canon using **pgvector**, and uses **IBM Granite** to reason about potential contradictions.

### My Contribution

I worked primarily on the **AI engineering side**:

- 🧠 LLM/provider architecture
- 🤖 IBM Granite integration
- 🔍 Fact extraction
- 🧩 Contradiction analysis
- ✍️ Prompt engineering
- 📦 Structured AI outputs
- 🔎 Semantic retrieval & embeddings
- ⚙️ AI pipeline orchestration

**Stack:** `Node.js` `Express` `PostgreSQL` `pgvector` `IBM Granite` `IBM Slate` `Next.js`
